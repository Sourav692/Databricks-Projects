# Databricks Projects

Monorepo for Databricks agentic applications. Each project lives in its own directory with its original layout and docs.

| Project | Path | Description |
|---------|------|-------------|
| **Bajaj RapidLR** | [`bajaj-rapidlr/`](bajaj-rapidlr/) | Agentic RAG IT support system for the RapidLR PL pipeline (Databricks, LangGraph, Vector Search). |
| **AIA Agent 360** | [`aia-multi-agent/`](aia-multi-agent/) | Multi-agent insurance intelligence system with a supervisor plus Genie, Multi-Tool, Data Analysis, and Visualization agents. |

This repository is **private** because Bajaj RapidLR is proprietary to Bajaj Finserv.

## Getting started

Open the project folder you need and follow that project's README:

- [bajaj-rapidlr/README.md](bajaj-rapidlr/README.md)
- [aia-multi-agent/README.md](aia-multi-agent/README.md)
